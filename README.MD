# Yandex API Region Parser

> 🚧 **Work in Progress**

Python service for enriching locality data with district information via **Yandex Geocoder API** and **PostgreSQL** storage.

The project is currently under active development. The architecture, functionality, and public API may change as new features are implemented.

## Tech Stack

* Python 3.12
* Yandex Geocoder API
* PostgreSQL
* Pydantic v2
* psycopg3
* Clean Architecture

## Development

The latest development version is available in the **`develop`** branch, where new features and ongoing changes are implemented.

## Status

This repository is a work in progress. Documentation, setup instructions, and usage examples will be added once the project reaches a stable release.
